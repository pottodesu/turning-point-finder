# turning-point-finder

技術や出来事を1つ起点に、その性質が人類の「当たり前の上限」を桁で外せるかを分野ごとに照らし、転換点になり得る未来を探す Claude スキルです。

- 例:筋力の上限→蒸気機関 / 固定窒素の上限→ハーバー・ボッシュ法 / 天然ゴムの量→石油(手袋)
- 起点の性質を20個以上挙げ、分野ごとの物理量の上限と突き合わせ、10倍以上動く組だけを候補にします。
- 候補を示したあと、前提を検索で確認するかを利用者に聞きます(トークンが増えるため)。確認した場合は、有力 / 条件つき / 連想のみ / 取り下げに分けて出力します。

## 使い方

`turning-point-finder/` フォルダを、Claude のスキルとして追加します。そのあと「〇〇が実現したらどうなる」「未来を想像して」のように話しかけると動きます。

## 動作確認した起点

核融合発電、AI、空飛ぶ車(eVTOL)。
