# turning-point-finder

未来を当てるスキルではありません。新しい技術や出来事が、人類が「当たり前」と思ってきた壁(増やせないとされてきたもの。面積・日照・埋蔵量・筋力など)を、越える材料になり得るかを洗い出す、思考の道具です。

## 何が得られるか

- **発想の叩き台**:企画・記事・調査の種になる「壁を越える候補」。候補の1/3以上は、起点の主目的の外にある性質から出します
- **見落としの確認**:起点から遠い分野(農業・医療・住宅など)まで、9〜20の分野の壁で照らします
- **誇張のない出力**:壁の原因が別にある候補や、物理的に成り立たない候補は取り下げます。越えた後に壁がどこへ移るかも示します

例:筋力の壁→蒸気機関 / 固定窒素の壁→ハーバー・ボッシュ法 / 天然ゴムの量の壁→石油(手袋)

## 出力の形

出力は、論理で読む「本文」と、根拠を置く「裏づけ」に分かれます。本文は各候補が次の4行です。

- なぜ動くか:壁の原因と、起点の性質がそれにどう効くか
- 何が止めるか:反証の要点
- 壁の移る先:越えた後に新しく壁になるもの
- まだ無いもの:成立に要る、まだ無い技術や仕組み

式・単位・出典リンクは、裏づけにまとめます。

## 向かないこと

予測や投資判断には使えません。候補に有力・条件つきのような区分はつけません。残った候補は、反証を受けても取り下げられなかった候補、という意味です。裏取りは軽いモデルが行うため、精度は中程度です。出典の本文が開けなかった場合は「本文未確認」と書かれます。

## 使い方

`npx skills add pottodesu/turning-point-finder`

手動で入れる場合は、`turning-point-finder/` フォルダを Claude のスキルとして追加します。そのあと「〇〇が実現したらどうなる」「未来を想像して」のように話しかけると動きます。

## 動き

1. 起点の主目的と性質を、20個以上挙げます
2. 9〜20の分野ごとに、今の壁を5個ずつ挙げます
3. 壁のうち人が動かせないとされてきたものを選び、壁の原因を書いて、起点の性質がその原因に効くかを判断します
4. 効く組を候補にします(最大12件)
5. 候補6件ごとに調査員を、3件ごとに反証役を、最も軽いモデル(Claude ならHaiku、Gemini ならFlash など)で同時に起動します。反証役は、成り立たない理由だけを探します。サブエージェントを使えない環境では、自分で順に行います
6. 物理的に成り立たない候補、壁の原因が別にある候補、起点の規模では壁に触れない候補を取り下げます
7. 本文と裏づけに分けて出します

## 動作確認した起点

核融合発電、AI、AIエージェント、空飛ぶ車(eVTOL)、合成燃料(eフューエル)。
