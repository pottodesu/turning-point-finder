# turning-point-finder

未来を当てるスキルではありません。新しい技術や出来事が、人類が「当たり前」と思ってきた上限(量・時間・面積・人数)のどれを桁で外せるかを洗い出す、思考の道具です。

## 何が得られるか

- **発想の叩き台**:企画・記事・調査の種になる「上限が外れる候補」
- **見落としの確認**:起点から遠い分野(農業・医療・住宅など)まで、物理量の上限で照らします
- **誇張のない出力**:上限が10倍以上動く組だけを候補にします。外れなければ「見込み薄」と返します

例:筋力の上限→蒸気機関 / 固定窒素の上限→ハーバー・ボッシュ法 / 天然ゴムの量→石油(手袋)

## 出力の例(起点:核融合発電)

> 電力でタンパク質を作る→農地あたり収量10倍超→「食料は農地と日照で決まる」が当たり前でなくなる

## 向かないこと

予測や投資判断には使えません。前提の確認をしない場合、候補はすべて「未確認」で出ます。

## 使い方

\`\`\`
npx skills add pottodesu/turning-point-finder
\`\`\`

手動で入れる場合は、`turning-point-finder/` フォルダを Claude のスキルとして追加します。そのあと「〇〇が実現したらどうなる」「未来を想像して」のように話しかけると動きます。

## 動き

1. 起点の性質を20個以上挙げます
2. 分野ごとの上限を、物理量で挙げます
3. 上限が10倍以上動く組だけを候補にします
4. 前提を検索で確認するかを利用者に聞きます(トークンが増えるため)。確認した場合は、有力 / 条件つき / 連想のみ / 取り下げに分けます

## 動作確認した起点

核融合発電、AI、空飛ぶ車(eVTOL)。
