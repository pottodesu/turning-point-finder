# turning-point-finder

未来を当てるスキルではありません。新しい技術や出来事が、人類が「当たり前」と思ってきた壁(増やせないとされてきたもの。面積・日照・埋蔵量・筋力など)を、越える材料になり得るかを洗い出す、思考の道具です。

## 何が得られるか

- **発想の叩き台**:企画・記事・調査の種になる「壁を越える候補」
- **見落としの確認**:起点から遠い分野(農業・医療・住宅など)まで、9〜20の分野の壁で照らします
- **誇張のない出力**:壁を越えない候補は取り下げ、確かめられない候補は「連想のみ」と区別します

例:筋力の壁→蒸気機関 / 固定窒素の壁→ハーバー・ボッシュ法 / 天然ゴムの量の壁→石油(手袋)

## 出力の例(起点:核融合発電)

> 人工光と大電力→耕地面積と日照の壁→「食料は畑の広さと太陽の量で決まる」が当たり前でなくなる

全体の例は [核融合発電の出力](examples/fusion-power.md) にあります。

## 向かないこと

予測や投資判断には使えません。裏取りは軽いモデルが検索3回までで行うため、精度は中程度です。「連想のみ」は、まだ確かめられていない候補として読んでください。

## 使い方

`npx skills add pottodesu/turning-point-finder`

手動で入れる場合は、`turning-point-finder/` フォルダを Claude のスキルとして追加します。そのあと「〇〇が実現したらどうなる」「未来を想像して」のように話しかけると動きます。

## 動き

1. 起点の主目的と性質を、20個以上挙げます
2. 9〜20の分野ごとに、今の壁を5個ずつ挙げます
3. 壁のうち人が動かせないとされてきたもの(面積・日照・埋蔵量・筋力など)を、起点の性質が越えられるかを物理だけで判断し、候補にします
4. 候補ごとに、使えるモデルのうち最も軽く安いもの(Claude ならHaiku、Gemini ならFlash など)を起動して、検索で裏取りします(1候補につき検索3回まで)。サブエージェントを使えない環境では、自分で裏取りします
5. 有力 / 条件つき / 連想のみ / 取り下げに分けて出します。有力は、未実証の技術を必要としない候補だけです

## 動作確認した起点

核融合発電、AI、AIエージェント、空飛ぶ車(eVTOL)。
